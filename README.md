# 🧪 Testes Unitários com JUnit

Este repositório contém o projeto prático consolidado durante o treinamento **Testes Unitários com JUnit** da **AlgaWorks**. O objetivo principal é preparar o desenvolvedor para escrever testes unitários eficientes e organizados para aplicações Java, seguindo as melhores práticas do mercado.

O repositório abrange diversas abordagens e mini-projetos (como simulações de e-commerce, sistemas de blog e classes utilitárias) desenvolvidos para explorar múltiplos cenários práticos de testes de software.

---

## 🎯 Sobre o Sistema e Conceitos-Chave

O projeto foca na implementação de fundamentos essenciais para garantir a qualidade de software, abordando:

- **Criação e Organização:** Configuração e uso do framework JUnit 5, além de boas práticas estruturais (padrão Triple A, BDD).
- **Simulações (Mocks e Stubs):** Uso de objetos falsos e dublês com Mockito para isolar testes e eliminar dependências externas.
- **Massa de Dados:** Padrões de projeto como Object Mother e Builder para trabalhar de forma limpa com dados fictícios.
- **Análise de Cobertura:** Configuração e uso do JaCoCo para descobrir lacunas e garantir que as regras de negócio sejam plenamente testadas.
- **Asserções Avançadas:** Implementação do AssertJ para tornar as verificações mais legíveis, semânticas e encadeadas.

---

## 📁 Estrutura do Projeto

O código-fonte é um projeto baseado em Maven, estruturado com o módulo da aplicação na pasta `backend`:

```text
aw-testes-junit5/
├── backend/
│   ├── src/
│   │   ├── main/java/      # Classes de produção (blog, ecommerce, utilidade)
│   │   └── test/java/      # Classes de teste unitário
│   ├── .mvn/               # Maven Wrapper
│   ├── mvnw / mvnw.cmd     # Executáveis do Maven Wrapper
│   └── pom.xml             # Configurações do Maven e dependências
├── .gitignore              # Arquivo de regras de ignorados do Git
├── LICENSE                 # Licença do projeto
├── README.md               # Documentação principal (Português)
├── README.en.md            # Documentação em Inglês
└── README.es.md            # Documentação em Espanhol
```

## 🛠️ Tecnologias e Ferramentas

- **Linguagem & Framework:** Java 17+, JUnit 5
- **Build & Dependências:** Apache Maven
- **Simulações (Mocks):** Mockito
- **Asserções Fluentes:** AssertJ
- **Cobertura de Código:** JaCoCo
- **IDE Recomendada:** IntelliJ IDEA
